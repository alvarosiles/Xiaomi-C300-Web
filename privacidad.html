En resumen

Este es un sitio estático de presentación. No tiene formularios, cuentas de usuario, cookies propias ni herramientas de analítica o publicidad. Solo se guarda en tu navegador la preferencia de tema claro/oscuro.

1. Responsable

Este sitio es un proyecto personal de portafolio de Alvaro Siles Estrada, publicado en GitHub Pages. Para cualquier consulta sobre privacidad, puedes abrir un issue en el repositorio del sitio.

2. Datos que se procesan

El sitio no recopila datos personales de forma directa. No existen formularios, registro, comentarios ni seguimiento propio.

Como ocurre con cualquier sitio web, al cargar las páginas tu navegador se conecta con los servidores que las entregan, que pueden registrar datos técnicos de la conexión (por ejemplo, dirección IP, fecha y hora, navegador y página solicitada). Estos registros los gestionan los proveedores indicados abajo, no el autor del sitio.

3. Servicios de terceros

ServicioFinalidadDatos técnicos
GitHub Pages (GitHub, Inc.)Alojamiento y entrega del sitioIP, navegador, página solicitada, para seguridad y operación del servicio

Cada proveedor trata esos datos según su propia política: Declaración de privacidad de GitHub y Política de privacidad de Google.

4. Almacenamiento local

Si usas el botón de tema, el sitio guarda en el localStorage de tu navegador una única clave, theme, con el valor light o dark. Este dato no sale de tu dispositivo y puedes borrarlo cuando quieras desde la configuración del navegador.

5. Cookies

El sitio no establece cookies propias ni utiliza cookies de analítica o publicidad. Por eso no se muestra un aviso de consentimiento de cookies.

6. Contenido de las capturas

Las capturas de pantalla muestran la aplicación real con una cámara de demostración: una fotografía de una oficina con licencia CC0 (Wikimedia Commons), sin personas. No contienen video de cámaras privadas, direcciones de red reales ni credenciales.

7. Tus derechos

Como el autor no almacena datos personales tuyos, no hay datos propios que consultar, corregir o eliminar. Para los datos técnicos que registran GitHub o Google, puedes ejercer tus derechos directamente ante ellos mediante los enlaces de la sección 3.

8. Cambios

Si el sitio incorpora nuevas funciones que afecten a la privacidad (por ejemplo, analítica o formularios de contacto), esta política se actualizará antes de activarlas y cambiará la fecha de última actualización.
